# Zero Form brand assets

The mark combines a zero with a folded form. The lowercase wordmark uses outlined Inter Bold with tight spacing.

| File | Use |
| --- | --- |
| `logo-mark.svg` | Square app mark on light or dark backgrounds. |
| `logo-light.svg` | Horizontal logo for light backgrounds. |
| `logo-dark.svg` | Horizontal logo with white lettering for dark backgrounds. |
| `favicon.svg` | Browser icon, legible at 16px. |
| `banner.svg` | 1280 × 640 social and README banner. |
| `logo-mark.png` | 512 × 512 mark with transparent corners. |
| `banner.png` | 1280 × 640 banner export. |

Colors: ink `#0E1116`, accent `#2B50FF`, paper `#F5F5F2`, confirmation green `#0F8A4F`.

All SVG artwork and lettering use paths, with no embedded raster images or external font dependencies. The SVGs include accessible titles. Keep the blue tile intact and leave at least one-quarter of the tile width around the logo. The banner includes its own margins.
